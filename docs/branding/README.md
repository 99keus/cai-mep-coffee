# Cai Mep Coffee logo system

Exported from the owner-supplied `logo-system-source.html`.

The 16 SVGs in `public/images/company/logo-system/` combine four layouts
(horizontal, stacked, symbol, compact) and four palettes
(primary, cream, reversed, monochrome). Lettering uses outlined Barlow Semi
Condensed Medium and SemiBold paths: no external font or stylesheet is needed.
Primary, reversed and monochrome assets have transparent backgrounds; cream
assets include the cream background shown in the source. Reversed assets are
intended for forest green or dark photographic backgrounds.

Palette: Coffee brown #3F2518; Forest green #1F3D2F;
Cream #EFE4D0; Copper #B87333. The supplied reversed copper is #D9955A.

Regenerate with Python and fontTools: `python3 scripts/export-logo-system.py`.
Font files are included in `fonts/`, with their SIL Open Font License.
